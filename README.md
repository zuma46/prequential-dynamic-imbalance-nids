# Prequential Evaluation of Dynamic Class Imbalance and Minority-Class Failure in Network Intrusion Detection

## Reproducibility package

This repository contains the public reproduction materials associated with
the manuscript **“Prequential Evaluation of Dynamic Class Imbalance and
Minority-Class Failure in Network Intrusion Detection”**.

Public reproduction release: **v1.0.0**.

## Study scope

The study evaluates chronology-preserving, minority-sensitive online network intrusion detection on two complete NetFlow v3 streams under a common 49-feature predictive contract. It uses prequential test-then-train evaluation, exact non-overlapping 50,000-flow temporal blocks, class-resolved evidence, and dependence-aware inference.

The controlled learner family is:

- Hoeffding Tree (HT), deterministic under the fixed implementation;
- Online Bagging (OB), five fixed seeds;
- Multiclass Oversampling Online Bagging (MOOB), five fixed seeds;
- Multiclass Undersampling Online Bagging (MUOB), five fixed seeds.

Fixed stochastic seeds: `123456789`, `234567891`, `345678912`, `456789123`, `567891234`.

## Data boundary

Benchmark datasets are **not redistributed** in this repository.

Obtain the original University of Queensland releases under the provider terms:

- NF-CSE-CIC-IDS2018-v3, DOI: `10.48610/ece9b83`
- NF-ToN-IoT-v3, DOI: `10.48610/44d7c5e`

The NF-CSE source requires the chronology correction implemented in `chronology/authoritative/e1_repair_cse_temporal_v1_1.py`. The chronology-corrected dataset is also not redistributed.

The generated relationship-analysis input `nonoverlap_block_class_metrics_derived.parquet` is intentionally not bundled. Its authoritative SHA256 remains recorded in the metadata and it is regenerated by the analysis pipeline.

## Research-question evidence map

The repository-facing mapping from the manuscript's three research questions to machine-readable evidence is documented in:

`docs/manuscript_evidence_map.md`

In brief:

- **RQ1**: temporal class support, lifecycle, disappearance, recurrence, minority switching, and dynamic imbalance;
- **RQ2**: within-class support–recall/minority-state relationships, support-qualified degradation and failure, DMAR/WAR evidence;
- **RQ3**: controlled HT/OB/MOOB/MUOB comparisons, treatment-coefficient contrasts, benign-FPR trade-offs, and mechanism diagnostics.

## Reproduction route

### 1. Acquire the two public datasets

Place the original benchmark files under a local data root. Portable scripts recognize:

- `E1_DATA_ROOT`: directory containing benchmark datasets;
- `E1_PROJECT_ROOT`: working E1 output/project root;

### 2. Reproduce chronology correction

```bash
bash reproduce.sh chronology --help
```

Run the authoritative chronology repair on the original NF-CSE release and verify the output against `metadata/authoritative_hashes.json`.

### 3. Reproduce prequential experiments

```bash
bash reproduce.sh experiment --help
```

Use the frozen configurations under `configs/` and runtime under `src/`.

### 4. Rebuild the final analysis

```bash
bash reproduce.sh analysis --help
```

The analysis reconstructs the principal temporal, lifecycle, class-level, sampling, and dependence-aware statistical outputs.

### 5. Reproduce the formal within-class relationship analysis

After regenerating the class-block parquet:

```bash
bash reproduce.sh relationship   --class-block /path/to/nonoverlap_block_class_metrics_derived.parquet   --out ./relationship_results
```

The default relationship-analysis bootstrap configuration uses 5,000 replicates and the frozen analysis seed encoded by the public entrypoint.

### 6. Compare with frozen reference outputs

Use:

- `results/manuscript_reference/`
- `results/relationship_v1_1_reference/`
- `results/authoritative_final_analysis/`

## Corrected temporal analysis

Run the original analysis pipeline first to generate both
`nonoverlap_block_metrics_derived.csv` and
`nonoverlap_block_class_metrics_derived.parquet` in an input directory.
Then run these commands from the repository root, using a separate output directory:

```bash
python analysis/temporal/run_analysis.py --input /path/to/derived --out /path/to/corrected
python analysis/temporal/sensitivity.py --input /path/to/derived --out /path/to/sensitivity
python analysis/temporal/check_undersampling.py --models src/e1_tdim_msb/models.py --out /path/to/muob_check.json
```

The parent directory for the diagnostic JSON must already exist.
The first command uses 5,000 bootstrap replicates, seed 20260805, and spans
of 10, 20 and 40 blocks. Undefined metric positions remain on the complete
chronological grid during resampling. Primary Holm families contain 36 tests
per dataset and span; the global sensitivity family contains 72 tests per
span. The minority-definition sensitivity family contains 16 contrasts.

For pairwise temporal inference and minority-definition sensitivity, these
newly generated outputs supersede the corresponding historical CSVs under
`results/manuscript_reference/` and
`results/authoritative_final_analysis/04_statistics/`. Do not use historical
pairwise p-values or intervals as the corrected results. Other frozen
summaries and the separate within-class relationship analysis retain their
existing roles. That relationship command uses its own seed, 20260831.

The second command reports per-seed failure, coarser-block summaries and
class/run influence checks. These checks are descriptive. The third checks
the actual tracker and Poisson repeat-update mechanism on synthetic input;
it does not measure detection performance. None of these three commands
retrains the original learners. Raw datasets and derived input files are
not redistributed; they must be obtained or regenerated through the existing
reproduction route.

## Statistical contract

- Exact primary temporal unit: 50,000 flows.
- Primary moving-block span: 20 blocks = 1,000,000 flows.
- Sensitivity spans: 10 and 40 blocks.
- Moving-block bootstrap replicates: 5,000.
- Primary support floor for formal failure/relationship reporting: 50 observations.
- Support sensitivity floors: 10 and 100 observations.
- Holm multiplicity adjustment is used in the manuscript-defined test families.

## Interpretation boundaries

The within-class coefficients quantify temporal associations within attack classes. They are not causal effects. Observed prevalence/lifecycle change is not treated as a ground-truth concept-drift oracle. MUOB is retained as a mechanism-specific negative result under the evaluated global-minimum undersampling rule and must not be generalized to all undersampling methods.
