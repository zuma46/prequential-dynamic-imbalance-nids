# Data and code availability

The benchmark datasets are publicly available from the University of Queensland:

- NF-CSE-CIC-IDS2018-v3, DOI `10.48610/ece9b83`
- NF-ToN-IoT-v3, DOI `10.48610/44d7c5e`

Code, frozen configurations, chronology-correction scripts, analysis scripts, reference outputs, and reproduction instructions are provided at:

https://github.com/zuma46/prequential-dynamic-imbalance-nids

The chronology-corrected NF-CSE-CIC-IDS2018-v3 file is not redistributed. Reproduction starts from the original public release under the provider terms and applies the included authoritative correction script.

The generated relationship-analysis class-block parquet is also not redistributed. Its authoritative hash is retained in repository metadata and it is regenerated by the analysis pipeline.
