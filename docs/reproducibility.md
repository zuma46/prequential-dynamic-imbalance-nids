# Reproducibility procedure

## 1. Data acquisition
Download NF-CSE-CIC-IDS2018-v3 and NF-ToN-IoT-v3 from the University of Queensland. Dataset files are intentionally absent from this package.

## 2. NF-CSE chronology correction
The evaluated NF-CSE stream was generated by a deterministic stable two-way merge on `FLOW_START_MILLISECONDS`. The operation changes row order only. The original source contains 20,115,529 rows and one strict inversion; the corrected stream contains the same rows and zero strict inversions. Verify source/output hashes in `metadata/authoritative_hashes.json`.

The public chronology script preserves the frozen merge logic while replacing machine-specific default paths with environment-root lookups. Set `E1_DATA_ROOT` for your filesystem. Source/public hashes are recorded in `metadata/public_portable_hashes.json`.

## 3. Runtime
Set `PYTHONPATH` to the repository `src` directory, or use `bash reproduce.sh experiment ...`. The evaluated entry point is `python -m e1_tdim_msb.cli`. Generated corrected NF-CSE v1.1 configs and validated NF-ToN v1.0 configs retain the frozen scientific parameters. For a new filesystem, change only dataset/output paths; retain model, seed, feature, window, and evaluation parameters.

## 4. Final analysis
The final analysis source is `analysis/e1_final_analysis_v1_0.py` with `analysis/e1_final_analysis_v1_0.yaml`. Public copies remove HPC-specific path defaults only. Paper reference tables are under `results/manuscript_reference/`.

## 5. Formal within-class relationship analysis
The formal relationship analysis begins from the generated `nonoverlap_block_class_metrics_derived.parquet`, locked SHA256 `f920643490e5d5441751c33536f262efd76655ed663b97255a3a6db485ccba67`. In accordance with the no-dataset release policy, that parquet is not bundled. The included v1.1 implementation preserves the full 402/550 temporal block topology before attack filtering.

## Expected scientific invariants
- 402 full exact blocks for NF-CSE and 550 for NF-ToN.
- 49 predictors for every evaluated configuration/run.
- No shuffle.
- Prediction precedes update.
- Stochastic seed aggregation is distinct from temporal replication.
- Overlapping 250k/500k/1M rolling windows are descriptive, not independent inference units.
